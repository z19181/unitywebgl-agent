## Bugs Fixed

### Bug 1: Infinite loop in `secret_scanner.js` (CRITICAL)
- **Root cause:** All 14 regex patterns lacked the `g` flag. `RegExp.exec()` without `g` returns the same match indefinitely.
- **Fix:** Added `g` flag to all patterns. Test process went from SIGKILL at 2GB heap → 5.5MB normal heap.
- **Impact:** All secret-scanning tests (T3, T4, T7, T12) were OOM-crashing.

### Bug 2: AUTH_TOKEN false positive on JWT
- **Root cause:** Regex `/token\s*[=:]/i` matched "Token: eyJ..." as auth token, preempting JWT_TOKEN detection.
- **Fix:** Split AUTH_TOKEN into access_token/auth_token pattern (`[=:]`) and generic token pattern (`=` only). Reordered JWT_TOKEN before AUTH_TOKEN.
- **Impact:** T4 now correctly redacts JWTs with `[REDACTED:JWT_TOKEN]`.

### Bug 3: PASSWORD false-positive skip
- **Root cause:** False-positive list `['password=']` skipped any match containing `password=` with length < 30.
- **Fix:** Removed false-positive entry. The regex `[^\s'"]{8,}` already prevents matching `password=` alone (no 8+ char value).
- **Impact:** T12 PASSWORD detection now passes.

### Bug 4: GITHUB_TOKEN test had wrong token length
- **Root cause:** Test token had 38 chars after `ghp_`, regex expects `{36}`.
- **Fix:** Corrected test token to `ghp_` + 36 chars.
- **Impact:** T12 GITHUB_TOKEN detection now passes.

### Bug 5: OOM on process exit (pool cleanup)
- **Root cause:** `db.js` singleton pool not closed in tests, causing SIGKILL during process shutdown.
- **Fix:** Added `db.closePool()` to the test preamble's `done()` function.
- **Impact:** Tests now exit cleanly at 768MB heap.
