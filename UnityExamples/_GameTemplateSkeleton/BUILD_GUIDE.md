# {GameName} Template Demo — BUILD_GUIDE

## 1. 环境要求

| 工具 | 版本 |
|---|---|---|
| Unity | 2022.3 LTS+ |
| Node.js | v18+ |
| PartyGameSDK Server | v0.2.7 |

## 2. 导入模板

```bash
cp -r _GameTemplateSkeleton/Assets/*  YourProject/Assets/
```

## 3. 一键生成场景

Unity 菜单: **Tools → PartyGame → Create {GameName} Template Scene**

## 4. 选择 WebGL Template

Player Settings → WebGL Template → **PartyGameTemplate**

## 5. Build WebGL

Output: `YourProject/Build/`

## 6. 接入 Server

```bash
cp -r Build/ PartyGameSDK-MVP/screen-build/
node server/server.js
```

## 7. 扫码测试

1. 打开 `http://localhost:3000/screen`
2. 扫描 QR Code
3. 操作 Controller → 观察 Unity → 检查分数

## 常见错误

| 错误 | 解决 |
|---|---|
| Unity 收不到消息 | GameObject 名称 "PartyGameBridge" |
| Controller 收不到广播 | server 运行中? broadcast 字段正确? |
